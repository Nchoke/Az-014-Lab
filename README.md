# Az-014-Lab
**Microsoft Azure Administrator Az-104 Hand-on-Lab**

This project demonstrates the deployment and administration of a hybrid Azure environment aligned with Microsoft AZ-104 objectives.

**Technologies Used**
Azure Virtual Machines
Azure Virtual Networks
Network Security Groups
Active Directory Domain Services
DNS
Azure Files
Recovery Services Vault
Azure Backup
Azure RBAC
VNet Peering
Environment
**South Africa North**
**DC01** (Windows Server 2025)
**Domain:** nchoke.pantech
**DNS**: 172.16.0.4
Windows 11 Client
**Central US**
**DC02** (Windows Server 2025)
**Domain**: pat.pantech
Implemented Features
Domain Join
DNS Troubleshooting
VNet Peering
Azure Files Integration
Recovery Services Vault
Azure VM Backups
RBAC
RDP Hardening with NSGs
Key Lessons Learned
Active Directory relies heavily on DNS.
Azure Files requires DNS resolution and SMB connectivity.
NSGs can restrict RDP access to a single public IP.
Recovery Services Vault provides VM-level protection.
